# Grades save locally, then sync

With browser-only authorization (ADR 0004) the Google token expires about hourly and a new one needs a popup inside a click. Rather than let that interrupt grading, each grade book's roster is kept in local storage and grades are saved there first, keyed by student, day and behavior name. They reach the sheet only when the teacher presses **Save to sheet**, which reauthorizes if needed, reloads the sheet, and writes the waiting grades to the matching rows and columns. Saving only on that click, even while a token is fresh, keeps one rule a teacher can learn: nothing is in the sheet until you press Save. A first-visit tip says so. A queued grade overwrites the sheet's value for that student and day, so this is last-write-wins per daily grade rather than the conflict-aware merge ADR 0002 describes. Roster, behavior and title edits still require Google but do not save queued grades; a behavior rename renames the key in queued grades so they still find their column.
