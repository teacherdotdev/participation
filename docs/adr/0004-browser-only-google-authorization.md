# Browser-only Google authorization

Google authorization moves from the auth broker's authorization-code flow with offline access to the Google Identity Services token client in the browser. The broker stored a refresh token and minted access tokens on request; now a Google popup returns an access token directly, and no refresh token exists anywhere. This removes the broker as a dependency and leaves no long-lived Google credential to store or protect, at the cost of a popup roughly every hour. Browsers only allow that popup during a click, so the app never contacts Google on page load: a returning teacher presses **Start grading** instead of landing on the roster, and synchronizing with Google (ADR 0001) can only start from a teacher's click once the token has expired. Every app origin must be listed on the OAuth client, which does not accept wildcards.
